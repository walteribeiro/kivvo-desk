# Kivvo Desk

Instaladores do aplicativo de balcão do [Kivvo](https://kivvo.io). O código do produto é privado; este repositório guarda só as releases, e o app se atualiza sozinho a partir delas.

- Windows: [Kivvo-Desk-Setup.exe](https://github.com/walteribeiro/kivvo-desk/releases/latest/download/Kivvo-Desk-Setup.exe)
- Linux: [Kivvo-Desk.AppImage](https://github.com/walteribeiro/kivvo-desk/releases/latest/download/Kivvo-Desk.AppImage)
- [Todas as versões](https://github.com/walteribeiro/kivvo-desk/releases)

O Desk precisa de uma conta Kivvo. O painel web funciona em qualquer navegador em [app.kivvo.io](https://app.kivvo.io).
